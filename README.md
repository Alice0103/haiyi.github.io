# Haiyi Yu — Portfolio (于海怡 · 作品集)

Personal portfolio of **Haiyi Yu (于海怡)** — AI & spatial designer based in Beijing.
Built as a static site (no framework, no build step) and vibe-coded together with Claude Code.

**Design & vibe-coded by Haiyi Yu with Claude Code · 本网页由我与 Claude Code 共同设计生成**

## Structure

```
index.html            home — the exhibition wall
perception.html       04 · graphic collage & posters
intersection.html     01 · izakaya & bar (day ⇄ night)
interlude.html        02 · fan-inspired residence
endless-life.html     03 · Banana Alley Vaults (adaptive reuse)
formation.html        05 · 3D fabrication
speculation.html      06 · future library CoLab
other-works.html      07 · point cloud / Lenovo / music
about.html            08 · resume & contact
assets/
  css/base.css        shared design system (bilingual typography)
  js/i18n.js          EN / 中文 language toggle engine
  img/                optimized imagery
  docs/               portfolio PDF, resume, .ply point cloud
```

## Features

- Bilingual EN / 中文 toggle (default: English)
- Camera-shutter entrance, crosshair cursor, custom menu
- Per-project signature interactions (day⇄night dial, CRT hologram viewer, material chips, layer focus, lightbox everywhere)
- Two-font system: Anton + Archivo (with Noto Sans/Serif SC for Chinese)
- Zero dependencies at runtime (three.js viewer on other-works loads from CDN with graceful fallback)

## Editing

The site is plain HTML/CSS/JS. Edit any page, commit and push — GitHub Pages redeploys automatically.
